# AYĀT Couture — Luxury Concept V3

Client-facing static UI concept prepared by NextWave Marketing.

## V3 improvements
- Cinematic multi-image homepage hero with smooth crossfade and slow Ken Burns zoom-in / zoom-out motion
- Refined deep couture teal, champagne-gold and warm ivory colour system
- Luxury page loader and subtle page transitions
- Scroll progress indicator
- Restrained parallax movement on editorial media
- Improved image hover motion and light-sweep detail
- Animated bridal / consultation popups and quick-view modals
- New atelier editorial section with private-viewing flow
- Desktop floating consultation CTA and mobile bottom CTA
- Existing responsive mobile UI retained and refined for motion safety
- Reduced-motion accessibility support

## Preview
Open `index.html` in Chrome / Edge. No PHP or backend is required for this concept.

## Production note
This is a frontend concept. A production build can later connect Laravel/PHP, MySQL, admin management, real appointments, product inventory, checkout, payment gateway, customer accounts and transactional email.
